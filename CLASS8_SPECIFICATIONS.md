## 🔍 DIMENSION BREAKDOWN

### 1. **Personality Preferences (PP)** - 10 Questions
**Questions:** 1-10  
**Options per Question:** 4 (A, B, C, D)  
**Scoring Codes:** PP-D, PP-S, PP-A, PP-C

**What it measures:**
- Personality type based on work style and preferences
- Decision-making approach
- Communication style
- Conflict resolution style

**Scoring System:**
- **PP-D (Decisive):** Action-oriented, leadership, direct
- **PP-S (Supportive):** People-focused, harmony, collaboration
- **PP-A (Analytical):** Detail-focused, logical, careful
- **PP-C (Creative):** Innovative, imaginative, open-minded

**Sample Questions:**
- Q1: "In a group project, you usually..."
- Q2: "When plans change suddenly, you tend to..."
- Q3: "At a party, you are most likely to..."
- Q4: "When solving a problem, you prefer to..."
- Q5: "Your ideal weekend looks like..."
- Q6: "When receiving feedback, you..."
- Q7: "In conflicts, you usually..."
- Q8: "You feel most energized when..."
- Q9: "When making big decisions, you rely most on..."
- Q10: "People would describe you as more..."

**Suggested Careers per Type:**
```
PP-D: Leader, manager, project coordinator, executive
PP-S: Counselor, HR specialist, teacher, social worker
PP-A: Analyst, engineer, scientist, quality controller
PP-C: Designer, innovator, strategist, creative director
```

### 2. **Career Interests - RIASEC (RI)** - 10 Questions
**Questions:** 11-20  
**Options per Question:** 5 (A, B, C, D, E)  
**Scoring Codes:** R, I, A, S, E, C (Note: No "C" for Conventional in all options)

**What it measures:**
- Holland's RIASEC model for career interests
- Preferred work activities and environments
- Natural inclinations toward different career fields

**Scoring System:**
- **R (Realistic):** Hands-on, practical, technical, building
- **I (Investigative):** Research, analysis, problem-solving, discovery
- **A (Artistic):** Creative, design, self-expression, aesthetics
- **S (Social):** Helping, teaching, counseling, people-oriented
- **E (Enterprising):** Leadership, sales, entrepreneurship, competitive
- **C (Conventional):** Organization, systems, data, order (optional)

**Sample Questions:**
- Q11: "Which task would you enjoy most?"
- Q12: "In a future job, you would prefer to spend time..."
- Q13: "Which school subject feels most natural?"
- Q14: "You feel most proud when you..."
- Q15: "Your ideal work environment is..."
- Q16: "Which project sounds most exciting?"
- Q17: "You like tasks that involve..."
- Q18: "When choosing electives, you lean toward..."
- Q19: "You would rather be known as someone who..."
- Q20: "Long-term, you see yourself in a role that is mainly..."

**Suggested Careers per Code:**
```
R: Engineer, technician, mechanic, trades, agriculture
I: Scientist, researcher, analyst, programmer, IT
A: Designer, artist, writer, media creator, content
S: Teacher, counselor, nurse, healthcare, social work
E: Manager, entrepreneur, salesman, business leader
```

**Questions:** 21-30  
**Options per Question:** 4 (A, B, C, D)

- Numerical reasoning

- Probability understanding

| 25 | Coding/Pattern | "If BOOK→CPPL, PEN→?" | QFO |
| 26 | Numeric Sequence | "2,3,5,8,12, ...?" | 17 |
| 27 | Probability | "4 red, 6 blue balls?" | 0.4 |

**Scoring Interpretation:**
Each answer (correct or incorrect) maps to career suggestions based on skill level:
- Correct answers → Recommended for analytical/technical roles
- Incorrect answers → Specific guidance on skill gaps

## 📈 SCORING APPROACH

### Raw Scoring:
- Each question (except AR with correct/incorrect) contributes to one or more dimensions
- Scores normalized to 0-100 scale
- Formula: `Math.round((score / totalQuestions) * 100)`

### Example Calculation:
```
RIASEC Dimension:
- Total questions for RIASEC: 10
- If student selects "R" option 3 times
- Score: (3 / 10) * 100 = 30% (Low Realistic interest)
```

### Mapping Strategy:
Each option directly maps to a score code:
- **Personality (PP):** Each option → one personality type
- **RIASEC (RI):** Each option → one career interest code
- **Aptitude (AR):** Correct/incorrect → skill level interpretation
- **MI (Multiple Intelligence):** Each option → one intelligence type
- **Others:** Similar direct mapping to dimension codes
