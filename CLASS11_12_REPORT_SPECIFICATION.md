```typescript
riasec_I = (Q8_I + Q9_I + ... + Q19_I) / 12
riasec_A = ...
riasec_S = ...
riasec_E = ...
riasec_C = ...

// Aptitude Score (Q20-Q31, 12 objective questions)
aptitude_score = (correct_answers / 12) × 100

// Strength Domains (Q32-Q43, 8 intelligences)
linguistic = (Q32_A + Q34_A + Q36_A + Q38_A + Q39_A) / 5
logical_math = (Q32_B + Q35_A + Q35_B + Q38_B + Q39_B) / 5
visual_spatial = (Q32_C + Q34_B + Q35_B + Q39_C) / 4
bodily_kinesthetic = (Q32_D + Q34_C + Q36_D + Q39_D) / 4
musical = (Q33_A + Q37_A + Q40_A) / 3
interpersonal = (Q33_B + Q38_C + Q40_B) / 3
intrapersonal = (Q33_C + Q37_C + Q40_C) / 3
naturalistic = (Q33_D + Q37_D + Q40_D) / 3

// Motivators Importance (Q44-Q49)
stability_preference = Q44 (A or B)
expertise_preference = Q45 (A or B)
autonomy_preference = Q46 (A or B)
financial_importance = Q48 (1-10)
meaning_importance = Q49 (1-10)

// Learning Style (Q50-Q52)
visual_auditory_kinesthetic = Q50 choice + Q51 choice + Q52 score

// Emotional Intelligence (Q53-Q56)
emotional_awareness = (Q53_score + Q54_score + Q55_score) / 3
feedback_receptiveness = Q56 (Yes/No/Unsure)

// Creativity (Q57-Q61)
creative_thinking = (Q57_E + Q58_E + Q59_E + Q60_score + Q61_score) / 5

// Academic Fit (Q62-Q69)
stream_fit_score = compare(riasec_profile, current_stream)

overall_career_readiness = (riasec_score + aptitude_score + creativity + clarity) / 4

```

```
   - Career clarity score (Q70: 1-10)
   - Decision stage (Q75: Decided/Narrowed/Exploring/Uncertain)

   Psychometric Alignment:
   - How RIASEC profile matches this career: X%
   - Aptitude match: Y%
   - Strength domains match: Z%
   → Overall Psychometric Fit: (X+Y+Z)/3 %
   
   Academic Alignment:
   - Current stream match: X%
   - Subject strengths alignment: Y%
   → Overall Academic Fit: (X+Y)/2 %
   
   Practical Alignment:
   - Post-Class 12 confidence (Q76): X/10
   - Willingness for alternatives (Q73): Y/10
   → Overall Practical Readiness: (X+Y)/2 %
   
   **OVERALL FITMENT SCORE: Average of all %**
   - 80-100%: Excellent fit - Strongly aligned
   - 60-79%: Good fit - Well aligned with minor gaps
   - 40-59%: Moderate fit - Need skill development
   - Below 40%: Needs reconsideration - Explore alternatives

3. Is This Career Realistic for Them?
   VERDICT: Highly Realistic / Realistic / Challenging / Needs Exploration

   - What they excel at that supports this career
   - What gaps exist and how to bridge them
   - Timeline to achieve this career
   - Entrance exams needed to reach this goal

4. Top 3 Alternative Careers (If Primary Goal Challenging)
   For each alternative show:
   - Career name
   - Fitment % with their profile
   - Why it could be a good fit
   - Path to reach this career
   - Comparison with primary goal

Visualization:
- Alignment radar (Psychometric vs Academic vs Practical)
```
