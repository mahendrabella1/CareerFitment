## 🎨 Design Highlights

### Visual Identity
- **Background:** Warm white gradient (not dark)
- **Primary Color:** Blue (#2563EB)
- **Secondary Color:** Indigo (#4F46E5)
- **Typography:** System fonts with 3 weights (semibold, bold, black)
- **Spacing:** Generous whitespace, relaxed padding
- **Feeling:** Premium, professional, educational, trustworthy

### Responsive Breakpoints
- **Mobile (320–767px):** Single columns, readable text, thumb-friendly
- **Tablet (768–1023px):** 2-column grids, readable layout
- **Desktop (1024px+):** 4-column grids, optimal spacing

### Animations
- Smooth entrance animations (fade + slide)
- Hover lift effects on cards
- Scroll-triggered reveals
- Stat counter animations
- Timeline progressive reveals
- All animations GPU-accelerated via Framer Motion
- Respects `prefers-reduced-motion`
